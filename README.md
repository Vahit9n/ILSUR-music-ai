
# 🎵 ILSUR MUSIC AI

Персональный Telegram-бот для управления музыкой и плейлистами Яндекс Музыки.

## Возможности

- Запуск через Telegram
- Просмотр плейлистов
- Поиск музыкальных треков
- Проверка настроек подключения
- Ограничение доступа по Telegram ID

## Команды

| Команда | Описание |
|---|---|
| /start | Запуск бота |
| /help | Список команд |
| /status | Статус настроек |
| /playlists | Мои плейлисты |
| /search | Поиск музыки |

## Установка

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Переменные окружения

Создать переменные:

- TELEGRAM_BOT_TOKEN
- YANDEX_MUSIC_TOKEN
- ALLOWED_TELEGRAM_USER_IDS

Настоящие токены нельзя публиковать в GitHub.

## Запуск

```bash
python bot.py
```
